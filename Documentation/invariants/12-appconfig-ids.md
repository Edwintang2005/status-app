# Invariant 12: AppConfig IDs stay in lockstep

Read before touching `AppConfig` identifiers, entitlements, `project.yml`, `Info.plist`.

**`AppConfig` IDs stay in lockstep** with the six entitlements files (app Debug and Release, widget, NSE, notification content, share), `project.yml`, and `Info.plist` `NSUbiquitousContainers`.
