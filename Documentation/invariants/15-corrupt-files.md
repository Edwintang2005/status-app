# Invariant 15: Corrupt store files are preserved, not overwritten

Read before touching `SharedStore.decode`, `MomentIndex`, `StatusHistoryLog`, `GroupFileStore.storedValue`, any new store file.

**Corrupt store files are preserved, not overwritten.** `SharedStore.decode`, `MomentIndex` and `StatusHistoryLog` move unreadable bytes to a `.corrupt` sidecar before falling back to empty; the index and the status log (its `onCorrupt` hook) then clear the change tokens so CloudKit refills them. Keep the pattern for any new file.
- Store files decode entry by entry (`LossyArray`, in `MomentIndex.swift`): a bad entry costs only itself, and a write that skipped some keeps the bytes in `.corrupt`. Own unsent sends an older build left in the sidecar are salvaged once by the retry pass.
- Sidecars don't outlive an unlink: `MomentIndex.clear()`/`StatusHistoryLog.clear()` remove theirs, `clearPairing` those of the keys it clears.
- *Unreadable* isn't corrupt: a file that exists but can't be read (before first unlock, I/O) sets `readFailed`; nothing is saved over it, and `SharedStore.record`/`refreshDerived` skip pruning and derived fields (`insertReadable`/`loadReadable` return `nil`, judged under the lock). A fresh start's local clear waits for both stores. The snapshot likewise: `GroupFileStore.storedValue` tells `.unreadable` from `.absent`, and `SharedStore.mutate` then runs no body and writes nothing. So does the pairing (`SharedStore.pairingState`): unreadable is never unpaired — `refresh` throws `SyncError.storeUnreadable`, the NSE leaves CloudKit's words held for upkeep to reword, the widget draws "Unlock to see the latest" (`SharedStore.isLockedOut` → `WidgetContent.isLocked`, never the unlinked look) and comes back in 15 minutes (`WidgetReloadPolicy.whileLocked`), not an hour; `requirePairing` throws `storeUnreadable` too, never `notPaired`.
- A kind from a newer build decodes as `Moment.Kind.unsupported(raw)`: filed under its own name, never prefetched or fetched (`ensureMedia`), shown in the library and gallery as an "Update to see this" placeholder (`UnsupportedMomentView`) that is never marked seen; its banner says to update.
