# Invariant 6: Widgets reload via SharedStore.reloadWidgets()

Read before touching `SharedStore+Widgets`, `WidgetReloadPolicy`, `refreshDerived`, the NSE's hold, `AppModel.redrawWidgets`.

**Widgets reload via `SharedStore.reloadWidgets()`** after a snapshot/media change, never from the widget process (`isRunningInWidgetExtension`); in-process calls use the instance (`requestWidgetReload`), so a test store stamps itself.
- An app/NSE reload stamps `widgetReloadRequestedAt` and the widget skips its fetch for `WidgetReloadPolicy.siblingReloadWindow` (2 min); `reloadWidgets(widgetNeedsFetch: true)` clears it (the NSE after an incomplete batch, failure or expiry). The NSE holds reloads for its run (`holdWidgetReloads()`, one idempotent release per exit).
- The app also redraws when it comes to the front and after its first fetch to work following a failure (`AppModel.redrawWidgets`, front-only: WidgetKit doesn't count those), so an outage's stale timeline never needs a restart. The widget records each run (`SharedStore.lastWidgetRun`, carrying the last real fetch through redraws that skipped one) for Diagnostics.
- Otherwise reload only when something drawn moved, and no caller decides that by hand: `mutate` compares `WidgetContent(drawing:reportedAt:)` before and after (the word filter left out — it only hides; a report kept in, as re-picked words lift it by date alone) — `WidgetContent` holds exactly what the widgets draw (each status's emoji and words, the partner's name, the picture's id, kind, caption and sender, the memo count, the heart's three dates), never `seen`, watermarks or receipts. A `mutate` that changes nothing writes nothing (an identical encode isn't rewritten either: `JSONEncoder.shared` sorts keys). What isn't in the snapshot reloads explicitly: the drawn picture's file arriving (`SharedStore.mediaLanded`, called by every download into the media store — thumbnails, full files, one moment's — so a gallery fetch, a restore's backfill or the expanded banner's sharpens the widget too), the filter switch, a report, `clearPairing`. A refresh's fold uses `write` and leaves its reload to the moments filed after it, so a delta costs one. Deferring is the one choice left to a caller: the gallery's paging (`refreshDerived(deferringWidgetReload:)`) reloads once on dismiss (`flushWidgetReload`). Every kind in `AppConfig.widgetKinds` reloads together (a new widget joins that list); they share one refresh (`SingleFlight`). The anniversary is drawn (the Together widget).
- Guarded by `WidgetRedrawTests`: every stored field of `Snapshot`, `StatusPayload` and `Moment` is classified drawn or not and checked against `mutate`; a new field fails it until classified.
