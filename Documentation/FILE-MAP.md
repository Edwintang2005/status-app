# File map

What lives where, file by file. The short version is in [CLAUDE.md](../CLAUDE.md).

Shared/
- `AppConfig.swift` (identifiers, tunables), `FoundationExtensions.swift` (`Date.wholeSeconds`, `wholeSecondsSince1970`, `Array.chunked(into:)`), `Theme.swift` (`warmDeep` behind white text; `accentText`/`warmText`/`mutedText` for AA text — `warm` alone is ~2.3:1 on cream, `accent` 4.25:1; `card()`/`card(shape:)`, `eyebrow`, `SquareFill`; headlines use `Theme.rounded`, never a fixed `.system(size:)`), `Waveform.swift`.
- `Models/` — `StatusPayload.swift` (`StatusPayload`, `PairRole`, `PairingInfo`, `Snapshot` — read its doc comments before adding fields), `FreshStart`, `Moment`, `Mood`, `Anniversary`, `MomentAttachment`, `ArchiveContents` (zone + local merged; local wins, reported stay out), `PhotoLocation` (where a photo was taken, in the full JPEG's own GPS tags — no record field; `stamped` merges them without re-encoding, the time as one ISO stamp; `read`; a partner's off-globe claim is refused).
- `Store/` — `SharedStore.swift` (KV over typed `StoreKey<Value>` names — plain names are raw-byte flags kept as they were — `mutate`, change tokens, and the flags: `verifiedAccount`, `nudgeRecordCache`, `statusRecordCache`, `wholePushID`/`lastPushID`, `subscriptionCleanup`, `subscriptionsVerifiedAt`; per device `cameraSettings`, `milestoneRemindersEnabled`, `notificationPreferences`, `notificationsNoticeDismissed`, `partnerLeftNoticeDismissed`) with its extensions: `+Widgets` (`record`, `refreshDerived(reloadWidgets:index:alongside:)` — derived fields + the caller's change in one write, returns `(changed, snapshot)` — `Derived`, reloads, `widgetReloadRequestedAt` and the reload hold), `+Unreadable` (`UnreadableTally`, `noteFetched`, `claimOwedRetry`), `+Diagnostics` (`BannerPass`, `WidgetRun`, `BannerProbe`, layout glitches, share launches, crash reports); `GroupState.swift` (`GroupFileStore`, UserDefaults migration), `CrossProcessLock`, `MomentIndex` (+ `LossyArray`), `RecapStore` (finished recaps, one per period, App Group `Recaps/` out of backups; erased with anything they could show — `eraseLocalMedia`, the fresh start's purge, a report, the filter switch, an own delete or caption edit (`Outbox`'s injected `clearRecaps`), and in `apply` a fetched deletion of a picture this phone held (`RecapPlan.invalidates`: not memos, not our own delete echoing) or a partner's caption edit on a picture; each clear is stamped beside the folder (`cleared(since:)`) so a run begun before it is gathered again, never resumed or kept; `removeYears(except:)` drops a year no longer offered, at launch and on keeping a new one; launch clears staging leftovers; Diagnostics deletes them), `MomentStore` (media, thumbnail and `gridThumbnail` caches; `write(_:id:location:)` stamps the full copy only, never the thumbnail; `imported` reads a picture from elsewhere at 2048 px without decoding the original; prune with 5-min grace sparing pending uploads and indexed thumbnails; `clearDownloaded` for Settings → Storage, keeping `Outbox.mediaToKeep`), `StatusHistoryLog`, `Outbox` (the send loops, receipt flush, the fresh start's steps, `upload`, and their `Snapshot` flag rules: `markStatusPublished`, `claimReceiptsDirty`, `stampPartnerStatusSeen`, …).
- `Cloud/CloudSync.swift` — the CloudKit actor's core (errors, record/field names, `changeFetchKeys`, account checks, `payload(from:)`), one extension per concern, members `internal`: `+Pairing` (share lifecycle, close handshake, `ownerPairing`, `existingZoneShare`), `+Status` (`pruneStatusLog`: non-atomic, drops locally only server-confirmed deletions), `+Refresh` (`fetchZoneChanges(…batchLimit:desiredKeys:)` — `.userInitiated`: CloudKit's default QoS is discretionary and missed the NSE's deadline on mobile data; so is every call someone waits on, through `CKDatabase.waited`/`CKOperation.Configuration.waited`: fetches by ID, full media, the account lookup, status/receipt/caption/anniversary saves — `apply`, `prefetchMedia` — one batched `records(for:)` per file kind), `+Nudges`, `+Moments` (`copyAsset` writes a `.part` then renames, so `hasMedia` never trusts a truncated file), `+Receipts`, `+Anniversary`, `+FreshStart`, `+Archive` (read-only whole-zone look), `+Subscriptions`, `+Unpairing` (`CKError` helpers, `retryingConflicts`). The most safety-critical code here.
- **What stays on the phone** (`MediaRetention`, the prune in `SharedStore.record`): full copies for the newest `momentImageCacheLimit` (60), thumbnails for the newest `momentThumbnailLimit` (500), both for unsent sends, favourites and the widget's picture (`latestPartnerVisualMoment`); older tiles fetch theirs as they scroll into view (`ThumbnailFetcher`), and the resync backfill (`MediaPrefetchPlan.missingThumbnails`) stops at the kept ones.
- **The index is swept to its cap once** (`HistoryCoverage`, `SharedStore.historyCoverage`): any `clearChangeTokens` owes a sweep; a kept token from a fetch with nothing more coming completes it, but only if the stored token was still the one that fetch began from (`startedFrom`); launch clears the tokens once when the index was filled under a smaller cap. While owed, every process's fetch is a resync (`fullResync`), and `ParsedDelta.outcome` files unknown partner moments that aren't news (created by `newsAfter`) as seen; `RecapPlan.needsZone(complete:)` treats an unswept index as short. Only an arrival (`insertReadable`) trims the index to the cap; other writes keep what's there. DEBUG: Diagnostics' "History (test)" pads the index to the cap with `MomentIndex.padding` (`test-pad-` ids, seen, pre-2020; `ensureMedia`/`ensureThumbnail` skip them) and times it (`MomentIndex.measure`). The app's frequent index writes (`markSeen`, `setFavourite`) go through `AppModel.writeIndex` — in order, off the main actor, `history` updated first and `reload` leaving it alone while one is queued. A refresh files arrivals off the main actor too, and loads the index only for a delta that touches moments. The recovery pass's media top-up (the latest thumbnail, missing favourites) runs beside it, not under its gate, and `ensureMedia` is bounded by `archiveItemDeadline`.
- Extensions take **one batch per refresh** (`batchLimit:` `extensionBatchLimit`, `RefreshResult.incomplete`) under a 24–30 MB ceiling; the batch token is a valid cursor and the app finishes the resync. The app's refresh is a loop of `appBatchLimit` (400) batches (`CloudSync.Sweep`), each filed and its token kept before the next, so a slow link's resync gains ground on every pass rather than losing it all at `refreshDeadline`; a batch from no token marks `historyCoverage` owed, so whichever pass continues the sweep judges it as a resync. Held or refused, a batch's token stays and the loop stops. It starts no batch past `AppConfig.sweepBudget` (90 s, under `refreshDeadline`) and returns what it filed, `incomplete`, for the next refresh to carry on; a later batch failing (offline, throttled — never a `SyncError` or cancellation) returns it `interrupted` too, with no owed-record retry: `SyncRunner` announces it, then throws `SyncError.sweepInterrupted`, so the earlier batches' news isn't lost and nobody reads the fetch as finished (the offline card, the reconnect catch-up). The token's compare-and-swap is under a cross-process lock (`SharedStore.setChangeToken(_:for:if:)`). An expired token's restart fetch goes to the zone-gone verdict like the first. `requeueMissingUploads` runs only for a whole sweep from no token whose batches each continued the last one's token (`Sweep.isWholeZone`) — a sweep its budget or a failed later batch cut short is carried to the next refresh (`Sweep.Carry`, app only, in memory) if nothing else moved the token in between — over every batch's names, and only for sends already confirmed before it asked (`sentBefore`), setting `RefreshResult.checkedWholeZone` — Diagnostics' "Re-check sent moments" (`AppModel.resyncHistory`) reports "nothing missing" only then; a miss in an earlier batch keeps `newsAfter` (`apply(missedEarlier:)`), and a complete sweep sets it from the newest any batch read (`readEarlier:`, `Sweep.newestRead`). `MediaPrefetchPlan`: the app takes the 10 newest of delta + index in full (own task); the widget the partner's newest photo/doodle in full + thumbnails of the next two; the NSE that thumbnail + its banner's attachment (`attachment(for:)`); extension downloads bounded by `widgetDeadline`; one landing after an unlink is deleted.
- `Cloud/` pure rules — `UploadPolicy` (`UploadWatch`, `UploadOrder`), `SharePosture` (`ShareMember`/`SharePosture`), `ParsedDelta` (`parse`, `outcome`), `RefreshDelta` (newer-wins fold), `TokenAdvancePolicy`, `StatusSavePolicy`, `ZoneGonePolicy`, `ZoneClearPlan` (`.unlink`/`.freshStart`), `AppFetchPolicy` (the app reuses another process's whole fetch: on foregrounding within 30 s — only while pushes reach the NSE, `lastPushID == wholePushID`, a token is stored — or after the stamped push; either way the recovery pass runs), `SingleFlight`, `ThumbnailFetcher` (≤50 per batch, ≤2 in flight, scrolled-away tiles withdrawn), `SendFailure` (`storageFull`, `offline`, `throttled(until:)`, `rejected`, `transient`), `CloudDiagnostics`.
- `Cloud/SyncBackend.swift` — the protocols (`SyncBackend`, the sync surface the send loops, runner and extensions see; `PairingBackend`, pairing and the invite link; the app holds `AppBackend`, both), `RefreshResult`, DEBUG `DemoBackend`, `UploadHandle` (an upload's progress and outcome), `withStallWatch`, `withDeadline` (bounds every widget/intent CloudKit call by `widgetDeadline`; a race that abandons the body, since CloudKit ignores cancellation — so `refresh` checks cancellation *before* `apply`, never between apply and the token, and `saveNudge` before its save).
- `SyncCoordinator` (+ `RunGate`: one run at a time, each caller's rule named — skip, join, or join and run its own pass once more), `SyncRunner` (an instance: store, backend, `SyncNotifier`, banner upkeep passed in).
- `AnnouncementPolicy` (`takeOwedMoments`, `isNews`, `seed` — pairing counts the partner's existing status as announced, words included, so their first rename is a rename), `PushBannerPolicy` (`decide`, `unpaired`, `attachmentDeadline`, `appAnnouncements`), `NudgeCooldownPolicy`, `FreshStartPolicy`, `ShareIntake` (the share sheet: `blocked` — terms, unlinked, partner left — `captionEdit` (return sends), `ShareLaunch` (each opening — process start, seconds to load and to on screen, outcome — newest 10 in `SharedStore.shareLaunches`, written by the sheet, shown in Diagnostics; "never on screen" is a launch the host gave up on), and its claim on a send — shortened by `closing` when the sheet closes mid-send, `nextLapse` waking the app's `sendQueued` — `SharedStore.shareUploadClaims`, which automatic retry passes, `sendDeletions` and the fresh start's clear wait out for `AppConfig.shareUploadHold` — a tap doesn't; dropped on a real failure, renewed on a timeout), `RecapPlan` (the year in review: ≤80 pictures in collages of 2–4 — `collages`, never one alone unless the period has one; `cells`, between square and 3:4 — and ≤8 statuses, spread evenly, in date order between an opening and closing card; always the Gregorian calendar in the phone's time zone (`RecapPlan.gregorian`; `unwrapping` floats); a Christmas gift — `unwrapping`, midday 25 December: the `reminder` notification then, Home's card until 31 January (neither once the partner has left), Settings the year before until it unwraps; `needsZone`: iCloud only when the period reaches past a full index — statuses never), `CameraPlan` (`CameraLensPlan`, `DualShotLayout`), `FillPlan` (the doodle's bucket fill: flood from the tap, bounded only by lines thickened by `gapRadius` — down to none for a narrower space — then grown back and one cell under them, as back-and-forth passes that `DrawingController.fill` draws as `.monoline` strokes — the ink tells a fill from a line — before every line, one undo step; a tap on a line recolours it, `lineHit`), `LayoutGlitch` (a sheet that opened blank — the status picker measures its content against its space 0.8 s in, records it in `SharedStore.layoutGlitches` for Diagnostics, and rebuilds once via `.id`), `CrashReport` (MetricKit's crash/hang reports from `jsonRepresentation()`, kept newest 20 in `SharedStore.crashReports`, filed by the app's `CrashReporter`, shown in Diagnostics), `Models/Celebration` (`CelebrationStyle` — a missing or unknown style plays confetti; `SeasonalMoods`; the reveal's seal), `WidgetReloadPolicy` (+ `TimelinePlan`; the schedule is in README "The remaining paths": faster while records are owed unreadable, `UnreadableTally.heldSince`, or a batch was `incomplete`; hourly whenever the widget's refresh found no route or no sign-in (`waitsQuietly`: `SendFailure.offline`, `notAuthenticated`, `accountTemporarilyUnavailable`, `iCloudUnavailable`) — reconnecting is the held APNs push's job; App/
- `RedStringApp.swift` (deep links `redstring://compose`, `redstring://open`, `redstring://moment/<id>`; sets `AppModel.current`), `AppDelegate.swift` (push registration, share acceptance via `InviteInbox`, banner actions — heart back, reply → `setStatus` with 💬, awaited; a moment's "Reply with a photo" → `Route.replyWithPhoto` (the composer, camera open after the sheet settles); `willPresent` re-reads for every banner, refreshes for remote pushes unless the NSE took that push's whole delta — `AppModel.refreshAfterPush`), `RedStringShortcuts.swift` (over `SendNudgeIntent`, compiled into app and widget).

Widget/ — `StatusWidget` + `WidgetViews` (status families; `NudgeWidget`), `MomentWidget`, `WidgetPhoto` (full JPEG downsampled via ImageIO; thumbnail fallback), `StatusProvider` (`StatusEntry` = `content` + `photo`, built once per timeline; one refresh across kinds; an 8 s CloudKit bound and cooldown flip-back entries; the systemSmall status tile uses text styles, accessory families stay fixed), `SendNudgeIntent`. NotificationService/ — dispatches on `subscriptionID` (never the delta), applies `PushBannerPolicy`'s plan, stamps `NotificationCategory` (none while unpaired), one widget reload per push, the worded fallback set before the bounded attachment fetch. NotificationContent/ — the expanded moment/status banner (`NotificationViewController`, `ExpandedBanner`): shows from the App Group, refreshes under `widgetDeadline`, tidies banners before and after; plays memos; `UserNotificationsUI` linked explicitly (imported alone, the extension draws nothing). Tests/ — `RedStringTests` (`FakeBackend.swift`), `RedStringUITests`. docs/ — the Pages site (GitHub Pages serves `main`'s `/docs` folder).
